> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The project lead may delegate coding/review through OpenCode CLI using only `opencode-go/deepseek-v4.1-flash`. Hermes subagents cannot spawn subagents. Do not select another coding model or recursively delegate.

**Goal:** Deliver an isolated no-login policy-PDF-to-accident-explanation-to-simulated-inboxes demonstration without touching production identities or claims.

**Architecture:** Independent FastAPI demo app and scoped ephemeral store, proxied by an allowlisted same-origin Next route. Deterministic page-grounded extraction/retrieval is the complete first milestone. Optional external-model assistance is a separately gated extension, not a fallback.

**Tech Stack:** Existing FastAPI/Pydantic/PyMuPDF/httpx/pytest; Next 14.2.35, React 18, TypeScript, existing Playwright; pnpm 9.1.4 and Poetry lockfiles. No database, Redis, embeddings, notification infrastructure or external model for deterministic operation.

Limits are enforced on server and tested at boundaries.
- Exactly one API worker, no production data-service/model credentials needed. No fabricated metadata, AI output, notifications, claim/coverage guarantees or silent AI fallback.

## Review Focus

1. Foreign-session IDs, idempotency replay and production-cookie forwarding must not expose or mutate another visitor's data (M1 and M2 privacy tests).
2. Malformed/encrypted/scanned/mixed/huge PDFs and a hung parser must fail honestly and within bounded resources (M1 extraction; M2 resource tests).
3. Missing/conflicting metadata, short header/footer terms and astral Unicode offsets must not invent facts or point at the wrong physical page (M1 evidence tests).
4. PDF/narrative instructions, HTML and fabricated provider citations must remain inert data or be rejected (M1 rendering; M3 provider tests).
5. Concurrent retries, reset/expiry/re-upload races and exhausted capacity must not resurrect state or duplicate simulated handoffs (M1 idempotency; M2 concurrency tests).
